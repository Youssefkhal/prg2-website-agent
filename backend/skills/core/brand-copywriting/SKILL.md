# Brand copywriting for websites

- Lead with the customer's problem and outcome, not with the company.
- Headline formula: [Outcome] for [audience] — without [pain]. Max 10 words.
- Sub-headline: how + proof in one sentence.
- CTAs are verbs + value: "Get my free quote", "Book a 15-min call". Never "Submit".
- One idea per paragraph, 2-3 sentences max, scannable bullets for features.
- Replace adjectives with facts: "24h delivery in Île-de-France" beats "fast service".
- Tone: pick 3 adjectives in the brief and stick to them (e.g. expert, warm, direct).
- About page: origin story (why) → mission → values (3) → team → numbers → CTA.
- Service block: Problem → Solution → Deliverables → Benefit → CTA.
- French copy: use "vous", French typography (espace insécable avant : ; ! ?, guillemets « »).
- Never invent client names, certifications or figures: use [à compléter] placeholders and tell the user.
