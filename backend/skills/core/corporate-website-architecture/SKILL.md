# Corporate website architecture

## Sitemap (default for an SME)
| Page | File | Goal |
|---|---|---|
| Home | index.html | Value proposition in 5 seconds, proof, main CTA |
| About | about.html | Story, mission, values, team, figures |
| Services / Products | services.html | One block per offer: problem → solution → benefit → CTA |
| Contact | contact.html | Form (mailto or static), address, map link, hours, phone |
| Legal notice / Privacy | legal.html | Mandatory in the EU (see skill legal-pages-eu) |
Optional: references/case studies, careers, blog, FAQ.

## Home page section order
1. Header: logo (left), nav (≤ 6 items), primary CTA button (right)
2. Hero: H1 = promise (≤ 10 words), sub-headline (1 sentence), 1 primary + 1 secondary CTA, hero image
3. Social proof: client logos / key figures (3-4 numbers)
4. Services overview: 3-6 cards (icon/image, title, 2 lines, link)
5. Why us / differentiators: 3 points
6. Testimonials (placeholders clearly marked if none provided)
7. Final CTA band
8. Footer: contact, nav, legal links, social, ©

## Brief template (/brief.md)
Company · activity · location · audience (personas) · tone (3 adjectives) · language(s) · brand colours (hex) · fonts · pages · CTAs · image list · constraints.
