# Conversion checklist
- Above the fold: promise, proof, CTA, visual — nothing else.
- Repeat the primary CTA every 2-3 sections; one primary action per page.
- Social proof near CTAs: logos, figures, testimonials (marked placeholders if unknown).
- Objection handling: FAQ (price, delay, guarantee, process).
- Process section: 3-4 numbered steps "How it works".
- Reduce form fields to the minimum.
