# Multi-Agent/Multi-Modal Collaborative Research and Development


#### Requirements

- Use `langchain`'s `deepagents` (https://docs.langchain.com/oss/python/deepagents/overview) to build an agent capable of extended reasoning.

- Prefer using `typescript` whenever possible. If `typescript` is used, the framework should be `nestjs`.

- If `python` is used, the framework should be `fastAPI`.

- Implement a web interface.

- Implement skill invocation, tool invocation, and subagent invocation.
- Implement dynamic registration of tools and skills. For example, if 1,000 skills are available locally, the context should include only the skills currently needed rather than registering all of them.
- Multimodal support: accept images and text as inputs.



#### Deliverable

The agent should be capable of being used to create a corporate website, including generating images and text together.
